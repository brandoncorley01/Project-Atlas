# Project Atlas — Product Requirements Document

See conversation-approved PRD. Summary:

**Mission:** Private AI decision intelligence dashboard ranking opportunities across options, stocks, sports, and cross-sport parlays.

**V1 scope:** Single user, in-app alerts, full signal cards with explainability, performance tracking.

**Out of scope:** Public site, Stripe, bet execution, brokerage integration.

**Build order:** Options first → News → Stocks → Sports → Parlays → Alerts/Performance.
